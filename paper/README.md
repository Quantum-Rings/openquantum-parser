# Upstream paper

The other files in this directory are the Journal of Open Source
Software paper for the original qasm-ts package. Sean Kim and
Marcus Edwards wrote it. Quantum Rings did not.

The article describes qasm-ts 2.0 as of 2025. It does not review
openquantum-parser. The text is unchanged from
https://github.com/comp-phys-marc/qasm-ts at commit a96b8e2.

Published version: https://doi.org/10.21105/joss.08696

JOSS articles are published under CC BY 4.0. Cite that paper for
the original qasm-ts work. Cite this package separately. See
`CITATION.cff` in the repository root.
